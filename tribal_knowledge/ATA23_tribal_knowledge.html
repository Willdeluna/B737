🎮 "It's Not the Radio" — Scenarios

Read first. Guess. Then reveal.

🎯 Change the LRU or Pass?

Answer YES or NO before revealing why.

Captain cannot hear ATC, FO can. Change COM1?

❌ NO. ACP or headset issue first. The radio is working — just not getting to that headset.

Both pilots lose comm simultaneously. Change both radios?

❌ NO. Simultaneous dual failures = shared system. Check the REU and routing first.

HF tuning tone never stops. Change HF radio?

❌ NO. 1 kHz tone during tune is normal. If it never stops, the antenna coupler can't find a match.

ACARS NO COMM. Change VHF?

❌ NO. ACARS uses VHF data, but failures are typically MU or mode selection.

Transmit fails but receive works. Change radio?

❌ NO. TX path is independent from RX. Check mic, PTT, and ACP transmit select.

Static on one radio only. Change radio?

❌ NO. Static = RF path. Inspect antenna and coax first.

🛠 Top 10 ATA 23 Tribal Knowledge Rules

The stuff that saves time and parts.
REU is the hub — if multiple issues at once, suspect the REU.
ACP lies to you if misconfigured — most “failures” are bad selection.
Transmit ≠ Receive — always treat the paths separately.
Dual failures = shared system — never two independent radios at once.
Mic and headset cause false failures — check them early.
RF problems ≠ LRU problems — static usually means antenna or coax.
HF problems = coupler problems — almost every time.
ACARS relies on VHF data — voice working doesn’t mean data works.
SATCOM uses ACP/REU chain — same troubleshooting logic applies.
Don’t swap parts until you prove the path — MIC → ACP → REU → RADIO → ANTENNA.

🔚 Bottom Line

If you remember nothing else: ATA 23 is an audio routing system. The REU is the hub, the ACP is the chooser, and the radios are just endpoints. Always trace the path before condemning a box.
