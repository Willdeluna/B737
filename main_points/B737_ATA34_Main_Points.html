✅ B737 ATA 34 • Navigation

Navigation Made Line-Mechanic Simple

Hover over each idea. ATA 34 is not one system — it's a data fusion system combining IRS, GPS, radio nav, and air data into one answer the pilots can use.

📍
Position Layer
IRS provides independent position. GPS provides satellite-accurate position and updates the IRS.
🧠
Fusion Layer
FMC combines all nav inputs, cross-checks them, and picks the most reliable source.
🖥️
Display Layer
PFD and ND show the result. Flags appear when source data goes bad.
🧠

Big Picture — Position, Direction, Path

ATA 34 gives the airplane its position and path→Where am I, where am I pointing, where am I going.big picture
Three core data types feed everything→IRS/GPS position, radio nav (VOR/ILS/DME), and ADC air data.data sources
Navigation = data fusion, not one system→FMC combines multiple inputs into one usable answer.real concept
📡

IRS — Inertial Reference System

Independent navigation — no radio needed→Provides position, heading, attitude, groundspeed.core function
Uses laser gyros and accelerometers→Measures movement internally — called dead reckoning.how it works
Alignment sets the starting position→Bad alignment = entire nav solution is wrong.critical step
IRS drifts over time→Needs GPS or radio updates to stay accurate.real limitation
🛰️

GPS — Modern Position Source

Highly accurate satellite position→Feeds the FMC and updates the IRS.core function
GPS corrects IRS drift→This is the key partnership — GPS keeps IRS honest.system synergy
GPS loss = accuracy degrades, not total failure→IRS keeps working — just less accurate over time.real impact
Antenna and receiver faults are very common→Check the antenna path before swapping the receiver.real mx reality
🧠

FMC — Navigation Brain

Combines IRS, GPS, VOR/DME inputs→Calculates the best estimate of aircraft position.central role
Picks the most reliable source automatically→GPS primary, IRS backup, radio nav for cross-check.smart logic
Cross-checks sources constantly→Mismatches trigger flags before they become problems.protection
📡

VOR / DME / ILS

VOR gives bearing to/from a ground station→Line-of-sight system with limited range.radio nav
DME measures distance from a station→Works alongside VOR or ILS — direction + distance.pairing
ILS gives precision approach guidance→Localizer for lateral, glideslope for vertical.approach aid
False signals can come from ground stations→Not always an aircraft fault — check the station too.real mx reality
🌡️

ADC — Air Data Computer

Provides airspeed, altitude, Mach, temperature→Uses pitot and static system inputs.core function
Bad ADC data = bad navigation AND flight controls→ADC faults ripple across many systems.huge impact
ADCs cross-check each other→Miscompare flags appear when they disagree.protection
🧭

Heading vs Track

Heading = where the nose points (IRS)→What direction is the nose aimed at right now.definition
Track = actual path over ground (GPS)→What direction the aircraft is actually moving.definition
Wind causes the difference between them→They are NOT the same thing — pilots use both.key concept
⚠️

Failure Modes & Reversion

Loss of one system = automatic reversion→IRS fails → use remaining IRS. GPS fails → IRS only.auto recover
MAP FAIL, IRS FAIL, NAV DATA flags appear→Tell you exactly which system is having trouble.diagnostic
Multiple system degradation = reduced accuracy→Not total nav loss — just less precise.real impact
🔧

Maintenance / Troubleshooting Gold

Most nav write-ups = miscompare or alignment→Not actual system failures most of the time.real mx reality
Always check IRS alignment quality first→Bad alignment masquerades as system fault.check first
BITE / FMC pages show the faulty sensor→Don't guess — let the system tell you.best practice
Antenna issues are very common→GPS and VOR antennas are exposed and fail often.common cause
Don't fix the display — trace the data→Displays are rarely the root cause.real mx reality
