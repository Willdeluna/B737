✅ B737 ATA 31 • Indicating & Recording

Indicating & Recording Made Line-Mechanic Simple

Hover over each idea. Think of ATA 31 as three jobs: display what the pilots need to see, alert them when something is wrong, and record what happened for later.

🖥️
Display Layer
CDS shows the pilots PFD, ND, engine, and systems data through 6 identical DUs driven by 2 DEUs.
🔔
Alert Layer
Master caution and aural warnings tell the crew when a system needs attention right now.
📊
Record Layer
FDR captures the last 25 hours of flight data through the FDAU for accident analysis.
🧠

Big Picture — What ATA 31 Really Does

Primary job = display + record aircraft data→What pilots see plus what gets recorded for analysis later.big picture
Four main parts work together→CDS displays, master caution, aural warnings, and flight data recorder.system map
Display issues are usually NOT the display→Trace back to DEU, power, or data input first.real mx reality
🖥️

CDS — Common Display System

6 identical Display Units run the cockpit→PFD, ND, engine, and systems displays — all interchangeable.core layout
Two DEUs are the brains→Both DEUs feed all 6 displays for full redundancy.redundancy
Data flow: System → DEU → video → DU→Coax couplers split the signal to all six screens.data path
Position pins tell each DU where it lives→If position not detected, the display goes blank.trouble clue
🔄

Automatic Reversion Logic

If a display fails, another takes over automatically→System reconfigures itself — don't assume multiple failures.auto recover
Outboard PFD fail → shows on inboard DU→Common reversion you'll see on the flight deck.example
Display Source Selector forces all to one DEU→ALL ON 1 or ALL ON 2 — great for isolating DEU faults.troubleshoot tool
⚠️

CDS Fault Messages — Know These

CDS FAULT = major problem→DEU failure or DEU mismatch. Big clue.high priority
CDS MAINT = partial failure→One circuit card failed. System still works.minor fault
DSPLY SOURCE 1/2 = all displays on one DEU→Configuration message, not always a fault.config info
INSTR SWITCH = both sides on same IR→Not a fault — just a configuration notice.not a fault
🔔

Master Caution System

Takes inputs from many systems→Turns on MASTER CAUTION plus the system annunciator.alert path
Ground signal = light ON→Most systems trigger master caution with a ground signal.logic basics
Recall button shows all active faults→Use it after a master caution reset to review everything.useful tool
Start at the system annunciator→It tells you which ATA chapter to look at first.troubleshoot start
🔊

Aural Warning System

Single module produces ALL sounds→Warnings, chimes, horns — one box does it all.central source
Triggered by discrete inputs→Various systems send ground signals to the module.input logic
Takeoff warning if config is wrong→Flaps, trim, or spoilers in wrong position triggers it.TO config
Some warnings cannot be silenced→Safety-critical sounds always play through.safety
📊

Flight Data Recorder System

Records last ~25 hours of aircraft data→Crash and fire resistant unit.core function
FDAU collects, FDR stores→QAR is optional for maintenance data collection.components
Runs automatically when engine running or in air→No pilot action needed — fully automatic.auto operation
Most FDR issues are FDAU related→The data acquisition unit fails more often than the recorder.real mx reality
🕒

Clock & Printer

Captain clock feeds time to many systems→FMC, FDR, and others use clock time.time master
Uses GPS time (UTC) or manual setting→GPS is the default — manual is the fallback.time source
Printer FLT light = paper or cover issue→Low paper or cover open are the usual suspects.common faults
🔧

Maintenance / Troubleshooting Gold

Most CDS issues = DEU or input, not screen→Don't swap displays first — check the data source.best practice
Check power before replacing LRUs→28VDC bus issues can mimic system faults.check first
PFD flags = bad data, not bad display→ATT, SPD, ALT flags point to the sensor.real mx reality
Holdup power loss triggers CDS FAULT→A power glitch will show as a CDS fault message.hidden cause
