✅ B737 ATA 49 • Auxiliary Power Unit

APU Made Line-Mechanic Simple

Hover over each idea. The APU is not just "a small engine" — it's a self-contained power plant with its own fuel, electrical, pneumatic, and protection systems. Follow Start → Run → Load → Protect.

✈️
Start & Run
Starter-generator spins the turbine. Ignition and fuel start the engine. ECU controls the entire sequence.
⚡
Produce Power
Generator provides 400 Hz electrical power. Bleed air supports engine start and aircraft systems.
🛡️
Control & Protect
ECU monitors EGT, speed, oil pressure, and sensors. Aggressive auto-shutdowns protect the unit.
🧠

Big Picture — Independent Power

APU = small turbine in the tail→Provides electrical power and bleed air without main engines.big picture
Three main jobs→Power on ground, start engines, backup power in flight.core roles
High altitude reduces capability→~90 kVA to 32,000 ft, dropping to ~66 kVA at 41,000 ft.altitude limits
✈️

APU Engine Design

Single shaft turbine engine→Compressor → combustor → turbine — runs at constant speed.core design
100% speed ≈ 48,800 RPM→Required to produce 400 Hz electrical power.operating point
Accessory gearbox runs starter-gen, fuel, oil→Single shaft drives everything off one gearbox.system layout
🌬️

Air Inlet Door — Often Overlooked

Door MUST be open before start→ECU verifies door position before allowing start.critical interlock
Door opens automatically with APU switch→Pilot doesn't manually open it.auto operation
Door position feedback is critical→Loss of signal = no start or shutdown.common fault
Stuck or unsynced door = #1 no-start cause→Check door position before troubleshooting deeper.real mx reality
🧠

ECU — Electronic Control Unit

Controls everything — fuel, speed, bleed, protection→Like a FADEC for the APU.central brain
Receives sensor inputs and aircraft signals→EGT, speed, pressure, oil temp, and more.input map
Drives start sequence automatically→Threshold-based logic — speed triggers each step.sequence control
🔥

Start Sequence

Inlet door → starter spin → ignition → fuel→Then self-sustain at ~7% speed.sequence overview
Ignition off at ~60% speed→Engine is self-sustaining at this point.transition
Starter disengages at ~70%→Mechanical decoupling protects the starter.protection
Ready to load at ~95%→Generator and bleed can now supply aircraft systems.ready state
⚡

Starter-Generator

Same unit motors for start, generates after run→Saves weight — dual function design.design
Power conversion: AC/DC → 270VDC → AC → starter→Complex electrical path during start.electrical path
Start system faults = usually electrical→Conversion units fail more than the motor itself.real mx reality
⛽

Fuel & Lube Systems

Fuel comes from the left main tank→ECU meters fuel based on speed, temp, pressure.fuel path
Fuel solenoid opens at ~7% speed→Synchronized with the start sequence.interlock
Oil pressure normal ≈ 60–74 psi→Low oil pressure triggers a shutdown after ~20 sec.limits
Oil temp >290°F also shuts down APU→Heat damages bearings — protection is aggressive.protection
🌬️

Bleed Air System

Provides air for start, packs, pressurization→Major integration point with ATA 36.cross-system
IGVs control airflow into the compressor→Adjusts based on bleed demand and conditions.flow control
Surge control valve dumps air if needed→Prevents compressor stall under low airflow.protection
⚠️

Protective Shutdowns

APU shuts down for fire, overspeed, overtemp→Plus low oil, no start, and sensor failures.shutdown triggers
Overspeed limit is ~106%→Fast shutdown to prevent rotor damage.limit
Shutdown closes fuel, ignition, IGVs→ECU does everything automatically.auto protection
Normal shutdown has 60-second cool-down→Prevents carbon coking — never bypass unless emergency.best practice
🔧

Maintenance / Troubleshooting Gold

Most APU faults = sensors or control logic→Not actual engine failures most of the time.real mx reality
Always check BITE before swapping hardware→Fault history and CDU pages are gold.best practice
Air inlet door = #1 no-start cause→Door position feedback issues are very common.common fault
Bleed system issues can look like APU faults→Cross-system troubleshooting — check ATA 36 too.cross-system
Data Memory Module stays with the APU→Not the ECU — fault history travels with the unit.useful detail
