Big Picture — How ATA 23 Works

REU = the audio brain of the airplane→Routes mic audio, radio audio, interphone, and alerts.core box
ACP = where crew controls everything→Select radios, volume, transmit, and monitor from here.
Everything audio passes through REU first→If audio gets weird across systems, suspect REU early.quick clue
🎧

Audio Control — ACP

Transmit on only one system at a time→The transmitter selector decides where your mic goes.
Listen to multiple systems at once→Receiver switches let the crew monitor several sources.
PTT sends audio to the selected system→Wrong selector = talking on the wrong radio.common write-up
ALT mode = emergency bypass mode→Direct mic to VHF radios with less system dependency.
⚠️

Emergency Audio Logic

Emergency mode bypasses REU logic→Keeps basic communication alive even with failures.highly testable
Captain / Observer → VHF 1→Hard-wired backup routing.
First Officer → VHF 2→Separate hard-wired backup path.
📡

Radio Systems — VHF / HF

VHF = primary communication system→Line-of-sight radio, used constantly in normal operations.
HF = long-range communication→Uses antenna coupler tuning to match the antenna.
HF tuning tone for a few seconds is normal→That 1 kHz tone means the system is matching the antenna.
HF tone over 15 seconds = likely fault→Big troubleshooting clue. Don’t ignore it.line mx clue
📟

Radio Control Panel — RCP

Any RCP can control any radio→Flexible control if a panel or radio path has problems.
PANEL FAIL = bad RCP→The control panel itself is the suspect.
FAIL FAIL = bad transceiver→The radio box is likely the problem.
---- ---- = no comm/data connection→Huge quick-isolation clue during troubleshooting.huge
🔔

SELCAL — Selective Calling

SELCAL = radio call without listening→Ground sends a coded tone to alert the crew.
Triggers chime + light on ACP→Crew then answers manually on the proper radio.
🧑‍✈️

Interphone Systems

Flight interphone = cockpit communication→Used between flight deck crew positions.
Service interphone = crew + ground communication→Connects cabin/crew/ground service points.
Ground interphone requires switch ON→Aft overhead switch OFF is a classic no-ground-comm trap.common mistake
📣

Passenger Address — PA

PA system uses priority logic→Cockpit beats attendant, attendant beats music.
Only one audio source at a time→No mixing. Highest priority wins.
Chimes tell you the event type→High = call, low = signs, high/low = crew call.listen clue
📡

ACARS — Data System

ACARS = text/data messaging system→Sends information to and from the airline.
Uses VHF radio for data link→It shares the communication radio system.
MSG light = incoming message→Always check the CDU.
🛰️

SATCOM — Long-Range Voice/Data

SATCOM = global voice + data via satellite→Works where VHF/HF may not, including polar areas.
Controlled through CDU + ACP→Not a fully standalone control setup.
Signal delays or drops can be normal→Don’t call everything a fault too fast.don’t chase ghosts
🎙️

Voice Recorder — CVR

Records the last 120 minutes of audio→Captures recent flight deck audio.
Records 4 channels→Captain mic, FO mic, observer mic, and cockpit area mic.
Erase only on ground with parking brake set→Safety logic prevents accidental erase.
RIPS backup power ≈ 10 minutes→Keeps recording after power loss.
🚨

ELT — Emergency Locator

Auto-activates on impact→G-switch triggers the transmitter.
Can also be manually activated→Cockpit panel gives crew control.
121.5 / 243 MHz = homing→Used to help locate the aircraft locally.
406 MHz = satellite tracking→Gives more accurate location, about 3 km.rescue signal
